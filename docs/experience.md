# Cloud Dispatch — descripción profesional

## Resumen para portafolio

Diseñé e implementé una plataforma de operaciones con API en C#, procesamiento asíncrono en Java y consola React. Incorporé persistencia transaccional, outbox, idempotencia, colas con reintentos, reportes de trazabilidad y auditoría serverless. Preparé la entrega mediante contenedores, GitHub Actions e infraestructura AWS CDK.

## Contribuciones verificables

- Desarrollé validación, separación de pedidos por identidad y contratos versionados entre servicios.
- Implementé recuperación ante reintentos mediante outbox PostgreSQL y tracking determinista.
- Construí el worker Java con SDK de AWS, almacenamiento S3 y confirmación privada de despacho.
- Implementé un handler Lambda C# para auditoría DynamoDB con fallos parciales e idempotencia.
- Creé una consola React con registro, búsqueda, filtros e indicadores operativos.
- Configuré pipelines de validación, publicación de imágenes y despliegue mediante OIDC.
- Definí infraestructura para red privada, cómputo distribuido, cifrado, autenticación, observabilidad y recuperación.
